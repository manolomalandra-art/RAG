# ALS Industrial Report — Context

## Project
Next.js 14 industrial report web app for ALS Global. Uploads tribology + financial CSV/Excel files, cross-references equipment health data, calls an LLM via Supabase Edge Function, generates downloadable PDF, and provides an AI chat with full file context.

## Architecture

### Layout
```
┌────────────────┬────────────────────────────┐
│ Upload zones   │   Chat (always visible)     │
│ (2 cols stack) │                             │
│                │   No files: site context    │
│ [Processar]    │   Files: full data context  │
├────────────────┴────────────────────────────┤
│ After processing: report table + PDF button  │
│ Chat stays below the report                  │
└──────────────────────────────────────────────┘
```

### Data Flow
1. **Upload** — 4 zones: Financial CSV, Tribology Excel, Thermography, Vibrations
2. **Parse** — `parseFinancialCSV()` normalizes fields, `parseTribologyExcel()` uses column-index based parsing
3. **Cross-reference** — `crossReference()` matches by key `(family|model|compartmentType)`, computes total cost = Part Cost + (Labor Hours × Labor Rate). Worst status (Normal→Caution→Abnormal→Severe) determines health.
4. **Edge Function `analyze-health`** — Receives pre-cross-referenced items, calls OpenRouter for evaluation/recommendation text, preserves original costs
5. **Report** — Table with green/red semaphore, cost breakdown. PDF download via `@react-pdf/renderer`
6. **Chat `chat`** — Edn Function that receives message + history + context. Context includes: raw tribology data, raw financial data, cross-referenced report, or site context (when no files uploaded)

### Tribune Excel Columns (1-indexed)
- 10=family, 11=maker, 12=model, 13=tag, 14=serial, 17=compartmentName, 18=compartmentType, 24=hoursAtSampling, 36=site, 39=status, 40=evaluation, 42=recommendation

### Financial CSV Headers
- `Familia de Equipamento`, `Fabricante`, `Modelo de Equipamento`, `Tipo de Compartimento`, `Nome da Peça Principal`, `Preço Peça (R$)`, `Horas Homem (HH)`, `Custo Tarifa HH (R$)`

### i18n
- Default: Portuguese (`pt`). Also Spanish (`es`), English (`en`)
- LangContext with modal selector. Translations in `src/i18n/`
